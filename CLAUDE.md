# Lump of Gold

Godot 4.7 project (Compatibility renderer). The active work is the **relief card editor**
(`relief/`, main scene `relief.tscn`): a tool for building segmented, game-ready character parts
from two-sided relief "cards" with baked detail maps, exported to Godot.

**Read `docs/DESIGN.md` before planning or building anything.** It holds the full plan (cards,
vectors, flow lines, baked maps, assembly, splines), the roadmap with status, open questions,
how the current code is laid out, and working notes (how to run, screenshot mode, gotchas).
Update its roadmap when a step lands.

The older three-view texture-encoded sculpt demo (`main.tscn`, `lump/`) is described in
`README.md`.
